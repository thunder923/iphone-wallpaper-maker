# スマホ壁紙メーカー

推しメンの画像をスマホの壁紙サイズに変換する、単一HTMLの無料ツールです。誰でもURLを開くだけで使えます。

**公開URL: https://iphone-wallpaper-maker.vercel.app/**
（予備: https://thunder923.github.io/iphone-wallpaper-maker/）

- 画像を画面サイズ（プリセット／カスタム／この端末に自動判定）に変換
- 余白はメンカラなど指定色の「幕」で充填（画像の平均色・ぼかし幕も可）
- 同じ人の画像を複数まとめて読み込み、同じ色・設定で一括書き出し（位置調整は画像ごとに保持）
- 「最適化」ボタン：画像の比率に合わせて、全体表示と画面いっぱいの間の程よい大きさに自動調整（寄せ具合はスライダーで調整可、全画像への一括適用も可）
- ロック画面の時計プレビューで、時刻まわりの見え方を確認しながらドラッグ／スライダー／1pxボタンで微調整
- 「全部リセット」で次の人用に画像・色・調整を一括クリア

画像はブラウザ（端末）内だけで処理され、外部に送信されません。

## 使い方

`index.html` をブラウザで開くだけで使えます（GitHub Pages でも配信）。
