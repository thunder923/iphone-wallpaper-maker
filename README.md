# スマホ壁紙メーカー

推しの画像をスマホの壁紙サイズに変換する、単一HTMLの無料ツールです。URLを開くだけで使えて、インストールは不要です。

**公開URL: https://iphone-wallpaper-maker.vercel.app/**
（予備: https://thunder923.github.io/iphone-wallpaper-maker/）

## できること

- 画像をスマホの画面サイズに変換して書き出し（PNG）
  - 端末プリセット: iPhone（初代SE〜17 Pro Max）/ Pixel / Galaxy / Xperia / AQUOS / Redmi など主要端末を用意
  - 開いた端末の画面サイズを**自動判定**して、合うプリセットを最初から選択
  - プリセットに無いサイズはカスタム数値でも指定可。初期値は 1290×2796（15 Pro Max 等）
- 余白は「幕」で充填。幕の作り方は3通り
  - **メンカラの幕**（好きな色を指定。推しのメンバーカラーなど）
  - **画像の平均色**から自動で決める幕
  - **ぼかし幕**（画像をぼかして引き伸ばした背景）
  - 時計の後ろだけ幕にしたい場合は「時計エリアの上幕」の高さも調整可
- **最適化**: 画像の比率に合わせて、全体表示と画面いっぱいの間の程よい大きさに自動調整。寄せ具合はスライダー（既定45%）で調整でき、全画像への一括適用も可
- **ロック画面の時計プレビュー**（白文字／黒文字）で時刻まわりの見え方を確認しながら、ドラッグ／拡大縮小スライダー／回転／1pxボタンで位置を微調整。画像が歪まないよう単一倍率で拡縮
- **複数画像の一括処理**: 同じ人の画像をまとめて読み込み、色・設定を共通化して一括書き出し（共有シートから写真アプリへ保存）。位置調整は画像ごとに保持され、「全画像にコピー」で揃えることもできます
- 「全部リセット」で画像・色・調整を一括クリアして、次の人用にすぐ切り替え

## 使い方

1. 公開URLをスマホ（またはPC）のブラウザで開く
2. 端末プリセットを選ぶ（開いた端末に合うものが自動で選ばれています。別の端末用に作る場合は手動で変更）
3. 画像を読み込む（複数枚まとめてOK）
4. 幕の色（メンカラ等）と幕の種類を選ぶ
5. プレビューを見ながら位置・大きさを調整（必要なら「最適化」で自動調整、時計プレビューで最終確認）
6. 書き出しボタンでPNGを保存（複数枚は「全部まとめて書き出し」→ 共有シートで「画像を保存」）

## データの扱い

- 画像はブラウザ（端末）内だけで処理され、サーバーや外部に送信されることは一切ありません
- 設定や画像がどこかに保存されることもありません。ページを閉じれば消えます

## 注意事項

- 書き出しはフル解像度で行われます（プレビュー表示だけ軽量化しています）
- 大きな画像を大量に読み込むと、端末のメモリ状況によっては動作が重くなることがあります
- ロック画面の時計位置は端末・OSバージョンで多少異なるため、プレビューは目安として使ってください
